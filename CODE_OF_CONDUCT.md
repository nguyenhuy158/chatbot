# Code of Conduct

## Our pledge

This project is a professional working environment. Everyone interacting with the codebase, issues, pull requests, and any communication channel agrees to maintain a harassment-free experience for all participants.

## Expected behavior

- Be respectful and constructive in discussions, reviews, and feedback.
- Critique code and ideas, not people.
- Assume good intent; ask before assuming bad.
- Use inclusive language.
- Respect different viewpoints, experience levels, and working styles.

## Unacceptable behavior

- Harassment, intimidation, or discrimination based on gender, sexual orientation, disability, ethnicity, religion, age, or any protected characteristic.
- Personal attacks, insults, or trolling.
- Publishing private information without explicit consent.
- Sexualized language or imagery.
- Sustained disruption of discussions.
- Any conduct that would be inappropriate in a professional setting.

## Enforcement

Report violations privately to the repository owner via GitHub:
https://github.com/nguyenhuy158

Reports will be reviewed within 7 days. Outcomes may include:

1. Private warning
2. Temporary suspension from project communication
3. Permanent removal from the project

The repository owner has final decision authority on enforcement.

## Scope

Applies to all project spaces: GitHub repository, issues, PRs, discussions, and any associated chat or email channels. Also applies to public spaces when an individual represents the project.
